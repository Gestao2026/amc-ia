# Apostila de Treinamento. CaptaHub

> Material para treinar uma pessoa sem experiência prévia a usar o CaptaHub. Combina a parte conceitual (o que o sistema organiza e por quê) com um roteiro prático de telas, pensado para ser completado junto com a pessoa treinada durante o primeiro acesso real à plataforma.

**Como usar esta apostila:**

1. Leia os Módulos 1 a 6 (parte conceitual) antes do primeiro acesso à tela. Sem entender a lógica por trás, decorar botão não ajuda em nada no dia a dia.
2. No primeiro acesso real ao CaptaHub, complete o Módulo 7 (passo a passo de telas) junto com a pessoa treinada, tirando prints de cada tela mencionada. Esse módulo está propositalmente em branco: foi montado a partir do acesso aos dados da plataforma, não da navegação visual, então precisa ser preenchido ao vivo, na frente da tela real.
3. Feche o treinamento com o Checklist do Módulo 8.
4. Use o Módulo 9 como roteiro de dois dias, se o treinamento for programado com antecedência.

---

## Módulo 1. Glossário essencial (comece por aqui)

Se a pessoa treinada é nova no setor de captação de recursos, sem esses termos o resto da apostila não faz sentido.

| Termo | O que significa |
|---|---|
| OSC | Organização da Sociedade Civil. Toda entidade sem fins lucrativos (associação, fundação, OSCIP) atendida pela assessoria. |
| Edital | Chamada pública de um financiador (governo, empresa, fundação) oferecendo recurso para projetos que atendam certos critérios. |
| Elegibilidade | Se uma OSC específica pode ou não concorrer a um edital específico, cruzando natureza jurídica, tempo de existência, território e documentos. |
| Proponente | A organização que se candidata ao edital, ou seja, a OSC. |
| Financiador | Quem lança o edital e paga pelo projeto aprovado. Também chamado de parceiro, patrocinador ou concedente, dependendo do tipo de edital. |
| Termo de fomento / colaboração | O contrato assinado entre a OSC e o poder público depois que o projeto é aprovado, previsto no MROSC. |
| Rubrica | Cada categoria de despesa do orçamento de um projeto, por exemplo pessoal, material de consumo ou equipamento. |
| Contrapartida | O que a OSC oferece com recursos próprios, além do que está sendo pedido ao financiador, como espaço, equipe ou insumos. |
| Prestação de contas | A comprovação, depois do projeto executado, de que o dinheiro foi usado exatamente como planejado. |
| Pipeline | A esteira de estágios por onde passa cada candidatura de uma OSC a um edital, do início ao resultado final. |
| Glosa | Quando o financiador não aceita uma despesa na prestação de contas e exige a devolução do valor. |

---

## Módulo 2. O que é o CaptaHub

O CaptaHub é a plataforma central de captação de recursos: é onde ficam os editais disponíveis, a carteira de clientes (as OSCs atendidas) e o pipeline de cada projeto em andamento, do primeiro contato até o resultado final. É a fonte da verdade: qualquer pessoa da equipe que precisar saber "que editais existem", "quais são nossos clientes" ou "em que pé está cada projeto" consulta o CaptaHub, em vez de perguntar para um colega ou procurar numa planilha solta.

O CaptaHub organiza o trabalho em três grandes blocos de informação, que conversam entre si:

```
EDITAIS  (as oportunidades)
    +
CLIENTES (as OSCs atendidas, a carteira)
    =
PROJETOS (o pipeline: cada candidatura de um cliente a um edital, acompanhada estágio a estágio)
```

Guarde essa equação. Ela é a chave para entender qualquer tela do sistema: tudo que você vai ver lá dentro é um desses três blocos, ou a ligação entre eles.

## Módulo 3. Bloco 1. Editais, o banco de oportunidades

O CaptaHub mantém um banco de editais permanentemente atualizado, aberto a todos os usuários da plataforma, não é exclusivo de cada conta. Isso poupa a garimpagem manual em Diário Oficial, sites de prefeitura ou grupos de WhatsApp. O banco reúne centenas de editais ativos, cobrindo escopo municipal, estadual, nacional e internacional.

Cada edital carrega estas informações:

| Campo | O que significa | Exemplo real |
|---|---|---|
| Título | Nome do edital ou chamada | "Chamada Pública - Educação 001/2026 - OSC" |
| Órgão / financiador | Quem lança o edital | "Municipal - Cotia, SP" |
| Escopo | Abrangência geográfica | Municipal, Estadual, Nacional ou Internacional |
| Categoria | Área temática | Educação, Cultura, Meio Ambiente, entre outras |
| Valor | Valor total ou teto do edital, quando informado | R$ 30.800.000,00 (ou "não informado", quando o edital não divulga) |
| Prazo | Data limite para submissão | 2026-05-29 |
| Fluxo contínuo | Se o edital recebe propostas o ano todo, sem uma janela fechada | sim / não |
| Link | Endereço oficial da fonte, para conferência | link direto para o edital |
| Descrição | Resumo do objeto do edital | "Edital para seleção de 22 projetos culturais..." |

**Como usar na prática:** ao buscar um edital para uma OSC, filtre por escopo, categoria e prazo mínimo para submeter. O CaptaHub descarta automaticamente editais com prazo vencido nas buscas por "somente abertos".

**Exercício:** peça para a pessoa treinada encontrar, no banco de editais, um edital de qualquer categoria com escopo estadual e prazo em aberto, e descrever os nove campos da tabela acima só olhando aquele registro.

## Módulo 4. Bloco 2. Clientes, a carteira de OSCs

Cada cliente cadastrado no CaptaHub é uma organização atendida (OSC). O cadastro reúne os dados que qualquer edital vai pedir para checar elegibilidade, então vale cadastrar completo desde o início, em vez de deixar para completar depois.

| Campo | O que significa |
|---|---|
| Nome / sigla | Razão social e nome fantasia da OSC |
| CNPJ | Documento de identificação da organização |
| Natureza jurídica | Associação, fundação, OSCIP, entre outras |
| Data de fundação | Usada para comprovar tempo mínimo de existência exigido por muitos editais |
| Município e UF | Sede da organização |
| Territórios de atuação | Onde a OSC efetivamente atua, pode ser diferente da sede |
| Área(s) temática(s) | Educação, cultura, esporte, meio ambiente, assistência social, entre outras |
| Missão | Resumo da missão institucional |
| Situação documental | Checklist de documentos em dia: CNPJ ativo, estatuto, CEBAS, certidões federal, estadual e municipal, FGTS, CNDT, cadastro no Transferegov |
| Histórico de aprovações | Projetos já aprovados anteriormente, com financiador, valor e ano |

**Por que isso importa:** a situação documental é o que decide se uma OSC pode ou não concorrer a um edital antes mesmo de escrever qualquer proposta. Manter esse checklist atualizado no CaptaHub evita perder tempo elaborando um projeto para uma organização que está com certidão vencida.

**Exercício:** peça para a pessoa treinada abrir o cadastro de um cliente real da carteira e apontar, na tela, onde fica cada um dos dez campos da tabela acima.

## Módulo 5. Bloco 3. Projetos, o pipeline de cada candidatura

Um projeto no CaptaHub nasce quando um cliente (OSC) se candidata a um edital. É o cartão que acompanha aquela candidatura do início ao fim. Cada projeto carrega:

| Campo | O que significa |
|---|---|
| Nome | Nome do projeto ou identificação da candidatura |
| Cliente vinculado | A OSC dona da candidatura |
| Edital vinculado | O edital ao qual está concorrendo |
| Status | Em qual dos 11 estágios do pipeline o projeto está agora |
| Nota técnica | Nota de 0 a 10 atribuída na avaliação antes da submissão |
| Chance de aprovação | Estimativa de chance, por faixa, por exemplo "28% a 38%" |
| Valor solicitado | Quanto está sendo pedido ao financiador |
| Valor aprovado | Quanto foi de fato aprovado, depois do resultado |
| Data de submissão | Quando o projeto foi enviado ao financiador |

### Os 11 estágios do pipeline, em ordem

É a esteira por onde todo projeto passa:

| # | Estágio | O que representa |
|---|---|---|
| 1 | Selecionado | O edital foi escolhido como oportunidade para aquele cliente |
| 2 | Encontrar cliente | Buscando qual OSC da carteira se encaixa nesse edital, ou o caminho inverso |
| 3 | Checklist | Checagem de elegibilidade e documentação em andamento |
| 4 | Contrato | Formalização da relação com o cliente para aquele projeto |
| 5 | Separar documentos | Reunindo a documentação exigida pelo edital |
| 6 | Elaborar projeto | Escrevendo a proposta e montando o orçamento |
| 7 | Submetido | Projeto enviado ao financiador |
| 8 | Aprovado | Resultado positivo |
| 9 | Reprovado | Resultado negativo |
| 10 | Pagamento pendente | Aprovado, aguardando o repasse do recurso |
| 11 | Pagamento recebido | Recurso recebido, projeto encerrado com sucesso |

**Como usar na prática:** todo projeto deveria estar sempre em algum desses 11 estágios, nunca "solto". Mover o cartão de estágio conforme o trabalho avança é o que permite que qualquer pessoa da equipe, ao abrir o CaptaHub, entenda o andamento de toda a carteira sem precisar perguntar a ninguém.

**Exercício:** peça para a pessoa treinada decorar a ordem dos 11 estágios sem olhar a tabela, e explicar em voz alta o que aconteceria se um projeto pulasse direto de "Selecionado" para "Submetido".

## Módulo 6. O ciclo completo, do edital ao pagamento

Juntando os três blocos, o fluxo típico de uma captação dentro do CaptaHub é:

```
1. Um edital aparece no banco (Bloco 1)
2. Ele é cruzado com o perfil de um cliente da carteira (Bloco 2)
3. Nasce um projeto (Bloco 3), começando no estágio "Selecionado"
4. O projeto avança estágio a estágio: encontrar cliente -> checklist -> contrato ->
   separar documentos -> elaborar projeto -> submetido
5. O financiador dá o resultado: aprovado ou reprovado
6. Se aprovado, o projeto segue até pagamento pendente e pagamento recebido
```

Cada estágio percorrido fica registrado, então o histórico de qualquer projeto pode ser reconstruído a qualquer momento: quanto tempo ficou em cada fase, quando foi submetido, qual nota recebeu, qual valor foi aprovado.

**Boas práticas de uso:**

- **Nunca cadastre um cliente ou um edital duas vezes.** Antes de criar, procure pelo nome ou CNPJ (no caso de cliente) para confirmar que ainda não existe.
- **Mantenha a situação documental do cliente sempre atualizada.** É a base de qualquer checagem de elegibilidade.
- **Não pule estágios do pipeline sem necessidade.** Um projeto que salta direto de "selecionado" para "submetido" esconde informação de quanto tempo cada etapa real levou.
- **Prazo vencido não é oportunidade.** Ao consultar editais, sempre confira a data de prazo antes de considerar um edital como candidato.
- **Valor "não informado" é diferente de "zero".** Quando o campo de valor do edital vem vazio, significa que o financiador não divulgou o valor, não que o edital não paga nada.

## Módulo 8. Checklist de treinamento

Use esta lista para validar que a pessoa entendeu a estrutura do CaptaHub, na teoria e na prática.

**Parte conceitual:**

- [ ] Sabe explicar, em uma frase, os três blocos de informação do CaptaHub: editais, clientes e projetos.
- [ ] Sabe quais campos compõem o cadastro de um edital e o que significa "valor não informado".
- [ ] Sabe quais campos compõem o cadastro de um cliente e por que a situação documental importa.
- [ ] Consegue listar, em ordem, os 11 estágios do pipeline de um projeto.
- [ ] Entende que projeto, cliente e edital são registros ligados entre si, nunca soltos.
- [ ] Sabe por que não se deve cadastrar cliente ou edital duplicado.
- [ ] Sabe explicar, com as próprias palavras, o que é elegibilidade, contrapartida e prestação de contas (Módulo 1).

**Parte prática (tela real):**

- [ ] Consegue fazer login sozinha(o).
- [ ] Consegue buscar e filtrar um edital por escopo, categoria e prazo.
- [ ] Consegue abrir o cadastro de um cliente existente e localizar a situação documental.
- [ ] Consegue cadastrar um cliente novo, sem duplicar um já existente.
- [ ] Consegue criar um projeto vinculando um cliente a um edital.
- [ ] Consegue mover um projeto de um estágio para o próximo no pipeline.

## Módulo 9. Roteiro sugerido de dois dias

Se o treinamento for programado com antecedência, esta divisão funciona bem para uma pessoa sem experiência prévia:

**Dia 1, parte teórica (Módulos 1 a 6):** leitura guiada do glossário, dos três blocos e do ciclo completo, com os exercícios de cada módulo feitos em voz alta, sem tela. Encerrar o dia com uma recapitulação oral dos 11 estágios, sem consultar a tabela.

**Dia 2, parte prática (Módulo 7 e Checklist do Módulo 8):** primeiro acesso real ao CaptaHub, completando o Módulo 7 tela por tela junto com a pessoa treinada. Fechar com o checklist completo do Módulo 8, teoria e prática, antes de liberar a pessoa para uso autônomo.
